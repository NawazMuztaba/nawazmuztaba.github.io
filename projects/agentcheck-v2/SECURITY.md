# Security scope and safe use

AgentCheck V2 Alpha is a personal research experiment with synthetic local resources. The public example illustrates an application Guard deciding whether a fictional request can reach a SQLite handler.

It is not an authenticated corporate identity system, a general-purpose AI tool firewall, an OS sandbox, a production MCP gateway, live SIEM collection or proof that all prompt injections will fail.

The public demo contains no external API and no LLM calls. It cannot prove the real private Qwen run and must not be described as the full V2 implementation.

**Safe operation:** use only invented data; do not connect credentials, employer/customer resources, real banking tools or untrusted external plugins. Contact the author privately about security issues rather than posting sensitive information publicly.

**Rights:** no broad open-source license has been selected for this case-study material or public demonstrator. Public visibility is not unrestricted permission for redistribution, derivative works or production deployment. The private APEX PermitLab codebase remains private.
